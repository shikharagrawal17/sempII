# Web3 Donation Platform (sempII)

A simple Web3 front-end application that allows users to connect their MetaMask wallets.

## Features
- Connect MetaMask wallet functionality
- Responsive navigation bar built with Tailwind CSS
- Pages planned: Home, My Donations, Enroll as NGO

## Technologies Used
- HTML5
- JavaScript
- Tailwind CSS

## Getting Started
Simply open the `index.html` file in any web browser and make sure you have the MetaMask extension installed to interact with the connection feature.
